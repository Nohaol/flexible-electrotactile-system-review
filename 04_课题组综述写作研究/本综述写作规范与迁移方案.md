# 本综述写作规范与迁移方案

目标论文：*Systematic Integration and Emerging Applications of Flexible Electrotactile Haptic Interfaces*。本文件将[五篇已核全文的横向发现](综述写作范式横向分析.md)转成 I、II、V 的实际写作检查标准。学习的是问题划分、证据排列和图表任务；**不用原文句子，也不把课题组综述当作电触觉原始实验依据**。

## I. Introduction：让综述范围由问题推出来

**借鉴方法。** [Y02 §I](代表性综述精读笔记/Y02_2023_皮肤电子材料设计应用.md) 用刚性电子和皮肤工作条件的矛盾立题；[Y01 Introduction](代表性综述精读笔记/Y01_2021_皮肤电子智能感知.md) 从检测转到感觉反馈；[Y08 Introduction](代表性综述精读笔记/Y08_2024_汗液电子系统链.md) 通过已有综述关注点与完整工作流的差距定义独特范围。

**具体迁移。** 段落任务建议为：① VR／遥操作／辅助技术需要低负担、可定位、可重复的皮肤反馈；② 电触觉的无机械运动部件、阵列可扩展等潜力与感知质量／阈值／皮肤界面不稳定并存（分别用领域原始研究支撑）；③ 说明现有触觉或材料综述未充分联接神经激活、界面传递与系统协同，文献对照需以实际覆盖范围为证；④给出本文独立问题：何种机制和界面条件决定可用刺激，系统如何在能量、通道、延迟和可穿戴条件下维持它；⑤以 Fig. 1 和章节路线收束。**避免**直接以“近年备受关注”开篇、把一般 haptic 改进等同电触觉进步、或把柔性外形当作系统级成功。

**人工检查：**

- [ ] 每个研究缺口对应至少一篇具体综述的覆盖范围或一组原始研究；不凭印象宣称“首次”。
- [ ] 明确电触觉与机械、热触觉的范围关系；说明本文聚焦 **flexible electrotactile interface**。
- [ ] Introduction 的结尾准确预告 II→III／IV→V→VI 的因果顺序，Fig. 1 与之同构。

## II. Fundamental Mechanism：按证据层级推论

**借鉴方法。** [Y09 §2→§3](代表性综述精读笔记/Y09_2024_柔性有机电化学晶体管.md) 先讲物理机制，再讨论器件条件；[Y02 §II→§III](代表性综述精读笔记/Y02_2023_皮肤电子材料设计应用.md) 用性能要求将材料和设计接起来。Y04 RSC 的摘要提示“机制→系统性能”的结构，但其正文尚未核读，不能作为细节依据。

**具体迁移。** II.1 保持现有英文正文不改。以后接续时，先写自然机械转导与经皮细胞外刺激的**不同生理入口**，分别标出神经生理、理论模型、心理物理实测可证明的层级；刺激参数—感觉关系须注明身体部位、波形、阈值定义和个体差异。II.2 再走刺激器→电极→双电层／角质层／组织→电场与有效刺激→知觉，比较等效电路各元件的物理意义及测量条件；只在实验证明时谈界面变化怎样影响阈值。以界面驱动需求衔接后续电路和 V，避免“低阻抗必然舒适”这类跳跃。

**人工检查：**

- [ ] 每句机制论断标明其证据层级：受体生理、模型、神经记录或主观心理物理。
- [ ] sensation、comfortable、discomfort／pain 阈值分别定义，未统一的研究不给通用数值。
- [ ] Fig. 2 的电场和纤维兴奋为概念示意，不画未经实测的受体／纤维选择性；Fig. 3 的电路参数附频率、接触条件和适用范围。

## V. System Integration：沿工作链和约束写，不按零件名单写

**借鉴方法。** [Y08 Fig. 1、Fig. 11](代表性综述精读笔记/Y08_2024_汗液电子系统链.md) 把完整工作链与实际功率需求并置；[Y01 Conclusions](代表性综述精读笔记/Y01_2021_皮肤电子智能感知.md) 把无线、存储和供电作为系统条件；[Y07 §§2–4](代表性综述精读笔记/Y07_2020_柔性纳米发电机.md) 提醒采能技术分机制而系统必须看负载。

**具体迁移。** 按“外部感知→采集→处理→触觉编码→多通道刺激驱动→柔性电极／皮肤→人体感知→反馈更新”建立主链。每节写**输入、输出、关键约束、代表实证与未解决权衡**：阻抗变化要求电流／电压顺应和监测；通道数改变寻址、互连与功耗；无线链路改变端到端延迟、计算位置与能量预算；封装／贴合改变接触稳定性。供电作为跨模块约束单独比较电池、无线供能、采能及储能；只有采能经管理后**实际驱动触觉脉冲且满足可重复感知**，才称自供能触觉输出。系统案例需同时报告触觉输出、负载、运行条件和人体验证。

**人工检查：**

- [ ] 每个模块写清与前后模块的耦合，而非只列技术名词。
- [ ] 区分自供能传感、采能辅助供电、真正自供能电触觉刺激。
- [ ] 延迟、空间分辨率、通道数、功耗、小型化的 trade-off 指向同一系统边界和测试条件。
- [ ] 完整系统主张要有整体展示证据；子模块论文只支撑对应模块。
