## 2. 可重复观察到的研究推进路径

**皮肤匹配 → 可用器件 → 多模态/编码 → 无线系统 → 任务闭环 → 能量自治。** 这不是每篇论文都有的单线进步史，而是本库相关工作之间较稳定的技术重心转移：2019 [贴肤无线触觉界面](https://doi.org/10.1038/s41586-019-1687-0)建立系统可穿戴性，2022 [手部信息编码](https://doi.org/10.1038/s42256-022-00543-y)处理人的感觉差异，2023 [多模态界面](https://doi.org/10.1038/s41928-023-01074-z)拓宽感觉维度，2022 [Touch IoT](https://doi.org/10.1126/sciadv.ade2450)与 2025 [无人机闭环](https://doi.org/10.1126/sciadv.adt6041)走向双向交互，2025 [自供能电触觉手套](https://doi.org/10.1126/sciadv.adt0318)挑战供电依赖。

与本综述相关的强项是贴肤柔性材料、无线、系统展示和应用闭环；II 的逐纤维募集、psychophysics 基础和经皮刺激动态电路，仍需用领域扩展文献支撑。不能把课题组系统中的受体示意图当成神经生理直接证据。

## 3. 问题提出：把真实使用矛盾具体化

2021 年综述的切入口是长期、实时皮肤表面健康/感知需求，随后指出传统器件与可穿戴场景之间的形变和舒适性矛盾。2023 年综述把矛盾具体分解为**刚性、Young 模量、皮肤运动、出汗和透气性**不匹配，再引入皮肤电子的材料与结构路线。这些是可检验的物理/使用限制，不是泛泛地说“需求日益增长”。2026 年皮肤触觉综述的网页则先解释触觉在人与物体交互中的作用，再把范围缩小到体表输出模态、器件形态和闭环。

建议用于本综述的抽象顺序：**任务中缺少哪类触觉信息 → 贴肤可穿戴需要哪些人体与工程条件 → 电触觉提供什么设计自由度 → 为什么仍受阈值、界面、驱动和能源约束 → 本文按人体—界面—系统组织。** 这是框架借鉴，不应复刻任何篇文章的原句或段落长度。

## 4. Introduction 的逻辑结构

| 稳定动作 | 在已读综述中的表现 | 本文 I 章可转化的动作 |
|---|---|---|
| 确定使用需求 | 长时生理监测、人工感觉或可穿戴触觉交互 | 从 VR/遥操作/假肢的触觉信息缺口进入 |
| 点出具体技术矛盾 | 刚性—皮肤运动不匹配；厚重/不透气影响长期佩戴 | 电极虽可薄软，感觉却受皮肤、神经和供电限制 |
| 给技术路线以因果理由 | 薄软、可拉伸、贴肤使信号/刺激更自然地耦合人体 | 电触觉的阵列、快速编程和无机械运动部件是优势，但要有证据边界 |
| 交代综述范围与章节 | 材料—设计—应用或感知—人工感觉—VR/AR | 人体感知与界面机制 → 柔性器件/驱动 → 系统与真实任务 |

## 5. 章节组织与分类维度

- **先定分类轴再放案例**：2023 年综述用材料、设计策略、应用三层，读者能先知道比较的标准。本文不能只按材料排列，应在 I 明确“人体机理、刺激界面、器件与系统”四层；在 V 按信息流和能源流排列。
- **分类服务问题**：同一技术在不同层的角色不同。例如水凝胶既可能是材料，也决定接触阻抗和佩戴舒适；无线电路既是器件，也影响闭环时延。分类应标主要作用和边界，不要求每篇仅出现一次。
- **每节回答上节遗留问题**：材料解决顺应性后，必须问导电接触是否稳定；界面稳定后，必须问能否输出可分辨且舒适的感觉；刺激可行后，必须问无线、能源和任务表现。
- **不把一般皮肤电子直接等同电触觉**：传感论文可以支撑材料或能源背景，但无法单独证明电刺激性能；自供能传感和自供能触觉输出分开。

## 6. 文献案例的组织方式

已读综述常以**一个性能障碍/功能目标为段落主旨**，选择数个方案展示材料、结构与应用之间的不同取舍，最后归纳可扩展性和未解决因素。适合本文的证据组织为：

1. 先写**论点的可检验版本**，例如“角质层水合会改变特定频带的界面阻抗”。
2. 再用**不同类型证据**，如 Rosell 的人体频谱、C05 的 24 h 凝胶电极、C03 的刺激动态模型，分别说明频散、时间漂移、脉冲非线性。
3. 最后说明**不能外推的部分**，如记录电极低阻抗不直接等于电触觉舒适；必要时指出下一步系统设计要求。

这一结构比“作者 A 做了 X，作者 B 做了 Y”的流水账更接近该组综述中的问题驱动节奏，同时保持本综述自身的证据逻辑。

## 7. 术语与表达习惯：提炼功能，不复用句子

从已读综述可归纳的术语组：`skin-integrated / skin-interfaced` 描述人体耦合形式，`conformal / stretchable / breathable` 描述机械和佩戴条件，`multifunctional / multimodal` 区分功能或刺激模态，`wireless / closed-loop / human–machine interface` 描述系统能力。写作时宜在首次使用时给**可测定义**：例如“breathable”要联系水汽/汗液与佩戴结果；“closed-loop”需说明反馈变量与控制更新；“self-powered”说明被供能的具体模块。

句法层面较稳定的是**需求句 → 限制句 → 设计方向句 → 综述范围句**的功能排列，以及**案例结果 → 系统价值 → 剩余约束**的段末回收。正式正文应根据本文证据重新写句，不翻译或拼接其英文表达。任何“首次”“显著优于”等比较级需原始证据支持。

## 9. 从材料与器件上升到 system-level discussion 的桥梁

不要在 V 重述 IV 的材料优点，而要问“材料改进**改变了哪个系统约束**”。例如透气织物可能减轻汗液积聚，但要追问阻抗/阈值漂移和佩戴时长；三维互连提高集成度，但要追问通道寻址、局部硬点和封装；TENG 提供机械电能，但要追问峰值电流、储能、静止可用性和多通道负载。案例必须经过**材料性质 → 接触/输出 → 电路代价 → 人的知觉 → 任务表现**这条桥梁，才能支持系统结论。
