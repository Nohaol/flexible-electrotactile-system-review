# II. Fundamental Mechanism：论点—文献—证据矩阵

核验日期：2026-09-29。每张卡片区分原始研究、综述与工程推论；“待核”处不得转写为确定量化结论。完整领域索引见 [领域文献索引](../领域扩展文献/领域文献索引.md)。

## 本章主链

自然触觉：机械刺激 → 皮肤变形 → 机械敏感末梢/LTMR → 传入纤维动作电位 → 脊髓和躯体感觉中枢 → 感知。

电触觉：刺激器 → 电极及角质层/组织中电场与电流 → 感觉神经末梢或轴突膜去极化 → 纤维募集与动作电位 → 人工知觉。具体被激活结构依电极几何、波形及组织分布变化；不能默认仅激活某一种机械感受器。

电路到感知：输出波形 → 接触与电极极化 → 角质层 → 活组织电流分布 → 神经兴奋 → 阈值和感觉质量。

## 参数、阈值与纤维募集的分层判断

- **直接生理作用对象**：跨皮电场改变感觉传入神经末梢或轴突的膜电位，达到兴奋条件后诱发动作电位。不同几何也可能影响皮肤内终末结构；不能把电极处的电流密度直接等同某一纤维实际跨膜去极化。[B01](https://doi.org/10.1016/j.neuron.2013.07.051)、[B02](https://doi.org/10.1109/10.68204)、[C03](https://doi.org/10.1371/journal.pone.0125609)。
- **自然触觉与电触觉的差别**：自然刺激先由机械转导通道把形变编码为感受器电位；电刺激使组织内电场直接改变可兴奋膜的电位，可能跨越正常的机械转导选择性。最终都通过传入动作电位进入躯体感觉通路。[B01](https://doi.org/10.1016/j.neuron.2013.07.051)、[A06](https://doi.org/10.1126/sciadv.abp8738)。
- **纤维类型**：低阈值 Aβ 触觉传入是目标之一；有毛皮肤中也存在 Aδ/C 低阈值机械传入，不能把所有 Aδ/C 纤维等同疼痛通路。刺激强度、位置与电极设计变化可伴随其他感觉传入募集和不适。表面电刺激缺乏充分的逐纤维记录证据，不能声称某参数精确选择某一 LTMR 亚型。[B01](https://doi.org/10.1016/j.neuron.2013.07.051)、[A05](https://doi.org/10.3389/frvir.2024.1406923)。
- **strength–duration**：用 `I_th(t)=I_r(1+t_c/t)` 作为经典 Weiss–Lapicque 型近似，仅在明确波形、电极和负载、目标纤维及阈值定义后解释 rheobase `I_r` 与 chronaxie `t_c`；不设全身通用数值。脉宽增加通常使所需阈值电流下降，但刺激电荷、痛感和局部电流密度也需分别评价。[B09](https://doi.org/10.1007/BF02368523)、[B04](https://doi.org/10.1038/s41598-022-10708-9)。
- **阈值分层**：sensation/perception threshold＝首次可觉察；comfortable operating range＝可分辨且可接受的工作区间（需每人、每部位校准）；pain、discomfort 与 intolerance 是不同主观终点，疼痛可先于不耐受出现。组织损伤安全限值另由电荷密度、皮肤完整性及电气安全确定，不能与主观阈值画等号。[B04](https://doi.org/10.1038/s41598-022-10708-9)。
- **个体/体区差异**：角质层厚度、水合、汗液、机械感受器密度、神经走行、贴合压力和电极定位共同变化；现有证据支持校准需求，但各因素的独立贡献及交互仍不足。[B03](https://doi.org/10.1088/1741-2560/6/6/066008)、[B07](https://doi.org/10.1186/1743-0003-8-9)、[Y02](https://doi.org/10.1038/s42256-022-00543-y)。

## 从阻抗变化到刺激稳定性：工程推论

在相同电极与波形且未触及电源/安全限制时，**电压控制**的界面阻抗上升可使输送电流下降；**恒流控制**为保持目标电流需更高顺应电压。这个关系是电路推论，真实脉冲受电容瞬态、局部电流分布、极化和时变皮肤状态影响，必须用实测脉冲和心理物理阈值验证。阻抗降低也不自动更安全：局部电流密度、热/电化学反应和不适可能上升。[C03](https://doi.org/10.1371/journal.pone.0125609)、[B06](https://doi.org/10.1109/TOH.2011.39)、[A06](https://doi.org/10.1126/sciadv.abp8738)。

### B03 Perception of electrical and mechanical stimulation of the skin: implications for electrotactile feedback
- **文献信息**：Patrick L Marcus, Andrew J Fuglevand；2009；*Journal of Neural Engineering*；[DOI: 10.1088/1741-2560/6/6/066008](https://doi.org/10.1088/1741-2560/6/6/066008)。

- **可用于本文的位置**：II.3 参数—感觉关系。

- **与于欣格课题组工作的关系**：互补：为于组个体化触觉编码提供非于组实验。
